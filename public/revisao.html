📦 Como Compartilhar com a Equipe

Opção 1: Via ZIP (imediata)

O ZIP já está pronto. Envie o ZIP para a equipe. Cada membro deve:

1. Extrair o ZIP
2. Abrir terminal na pasta extraída
3. npm install
4. npm start
5. Abrir http://localhost:3000

Opção 2: Via GitHub (necessário para nota máxima)

Passo 1 — Instalar Git: Baixe em https://git-scm.com/download/win. Instale com as opções padrão e reinicie o VS Code / terminal.

Passo 2 — Criar conta no GitHub (cada membro): Acesse https://github.com/signup e crie uma conta com email pessoal.

Passo 3 — Um membro cria o repositório: No GitHub, clique em "New repository". Nome: sistema-universitario. Marque Public. NÃO adicione README nem .gitignore. Clique "Create repository".

Passo 4 — Subir o código:

cd C:\projetos\sistema-universitario
git init
git add .
git commit -m "Entrega 2 - Sistema de Gestão Universitária"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/sistema-universitario.git
git push -u origin main

Passo 5 — Adicionar membros: No repositório GitHub → Settings → Collaborators. Adicione cada membro pelo username do GitHub. Cada membro aceita o convite.

Passo 6 — Cada membro faz um commit:

git clone https://github.com/SEU_USUARIO/sistema-universitario.git
cd sistema-universitario
# Editar qualquer arquivo (ex: adicionar um comentário)
git add .
git commit -m "Contribuição de [NOME DO MEMBRO]"
git push
