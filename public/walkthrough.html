Sistema de Gestão Universitária • Projeto Integrador — 4º Semestre TADS/TSI • SENAC EAD 2026

🎯 O que foi implementado

O sistema UniGestão foi desenvolvido como prova de conceito completa, cobrindo os 4 cenários definidos na 1ª entrega:

Cenário Funcionalidades
Matricular Alunos Cadastro com validação de idade ≥ 18, matrícula em curso, geração automática de boleto
Consultar Docentes Listagem alfabética, busca por nome, visualização de disciplinas, ativar/inativar
Inativar Fornecedores Verificação de pendências (pedidos em aberto), confirmação, reativação
Gerenciar Notas Seleção por curso/disciplina, edição inline, bloqueio de notas consolidadas e matrículas trancadas

🛠️ Stack Tecnológica

Camada Tecnologia Justificativa
Frontend HTML5 + CSS3 + JavaScript SPA com navegação sem recarregamento
Backend Node.js + Express API REST com 18+ endpoints
Banco de Dados SQLite (sql.js) Zero configuração, auto-inicialização
Design Dark Theme + Glassmorphism Interface premium e moderna
